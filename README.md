# 🤖 AI Chatbot — AI Friend

> A friendly AI chat app. Ask anything on any topic and get a clear answer in English — the conversation is remembered, and every chat is saved for later.

---

## ✨ About

**AI Friend** is a simple, clean chat app powered by an AI assistant. It remembers what was said earlier in the same conversation, so follow-up questions just work. All chats are saved in the sidebar — reopen an old chat anytime, start a fresh one, or delete the ones you don't need.

## 🚀 Features

- 💬 **Real AI answers** — ask about anything: study, work, ideas, everyday questions
- 🧠 **Conversation memory** — the AI remembers the context of the ongoing chat
- 🗂️ **Saved chats** — every conversation stays in the sidebar, ready to reopen
- ✨ **Starter questions** — 6 ready-made prompts to begin with one tap
- 🇬🇧 **Always in English** — replies stay in English even if you type in another language
- 🗑️ **Delete chats** — remove a conversation with a confirmation step

## 🎮 How to Use

1. Type your message and send — the AI replies with a typing indicator.
2. Keep the conversation going; context is remembered.
3. Use the sidebar to switch between chats, start a new one, or delete an old one.
